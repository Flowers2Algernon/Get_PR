## 二、 深度拆解：高才通 vs 新版优才（12 选 6），我该走哪条？

### 1. 高才通 (TTPS) 的核心规则与“唯一性警告”
* **⚠️ 终身只能获批一次！** 高才通一旦获批，如果你 2/3 年后断签了，**这辈子不能再申请第二次高才通**（只能改申优才、专才或去读书拿 IANG）。所以**“没有想好 2 年后怎么续签，千万别盲目下签激活！”**
* **百强大学名单陷阱（B类/C类）**：
  * **只看本科学士学位（Bachelor's Degree）！** 哪怕你是哈佛、牛津、港大的硕士或博士，只要你本科是普通双非院校，就**不符合**高才通 B/C 类资格（请转头走新版优才！）。
  * 内地共有 **23 所左右高校**在合资格名单内（清北复交浙、中科大、南大、华科、武大、中大、哈工大、西交、北航、同济、北师大、南开、天大、川大、山大、吉大、中南、厦大、北理工等，以入境处当年最新更新的 198/199 所合资格大学名单为准）。
* **A 类（250万港币年收）避坑**：
  * 必须是申请前 12 个月的**应课税就业或业务收入**（工资薪金、奖金、已行权股票期权，或持股 ≥ 50% 的独资/合资企业经审计的税后利润）。**炒股收益、卖房收入、分红（持股不足50%）统统不算！** 且不能临时补税凑数。

## 三、 生死存亡战：高才通 / 优才下签后，第 2/3 年到底怎么续签？

香港入境处对于高才通和优才续签的核心原则只有八个字：**“实质贡献，真实联系”**。千万不要相信黑心中介所谓的“2万块挂靠空壳公司买强积金（MPF）包续签”——**虚假雇佣在香港属于刑事重罪，已有多批黑中介和申请人被判入狱并取消身份！**

### 四大合法合规续签路径（按稳妥程度排序）：

#### 1. 在港受雇路径（最稳妥，直接批 3 年）
* 受雇于香港本地正规公司，担任学位程度岗位，薪资达到市场水平（建议月薪 ≥ 2万~3万港币），按月发薪、缴纳强积金（MPF）并申报香港薪俸税。
* **变通玩法（跨境外派）**：受雇于香港公司，但因业务需要被外派回内地大湾区或海外办公，只要**劳动合同签在香港、部分或全部薪资由香港主体发放并在香港依法报税**，且定期回港汇报留有出入境记录，完全可以顺利续签！

#### 2. 在港创业/自雇路径（适合自由职业者、独立开发者、跨境电商/咨询老板）
* 在香港真实注册一家有限公司，**租用实体办公场所**（共享办公独立工位或商业大厦办公室，不可仅用秘书公司虚拟地址！），产生真实业务合同与银行流水，依法做审计报利得税，给自己发放薪水并交 MPF。
* **独立开发者/自媒体/咨询师**：可以把你的海外 Stripe 收入、SaaS 订阅收入、跨境贸易或咨询业务合规装进自己的香港公司里运营，既享受香港 8.25%（首200万港币利润）的超低利得税，又完美解决续签！

#### 3. 非雇佣/佣金制工作路径（保险经纪 / 财富管理顾问等）
* 入境处虽允许以非雇佣合同形式在港工作（如持牌保险代理），但**对收入流水真实性、洗钱返佣、在港实际居留天数审查极严**。如果每年只有几万港币挂名业绩且常年不在香港，极大概率只批半年到1年观察期，甚至直接拒签。

#### 4. 优才“通常居住”软性续签（仅限优才，高才通不适用！）
* 如果主申请人实在无法长居香港，但**配偶在香港全职工作/读书，且子女在香港本地读书、在香港有长期租房/买房合同**，优才首次续签仍有机会获批 1~3 年（但后续第 2 次续签及转永居时，主申请人仍需补充实质赴港贡献）。
