# 🇯🇵 日本：工作在留与永住申请资料目录

修订日期：2026-10-25。积分达到门槛、获得工作在留资格与永住许可是不同结果；不把“最快可申请”写成“保证拿到”。

## 路径怎么选

| 路径 | 首先核对 |
| :--- | :--- |
| 高度专门职（HSP） | 活动类别、接收机构、适用积分表、收入及证明 |
| 技术・人文知识・国际业务 | 具体工作与学历／经验、雇佣条件；不同活动的例外分别查 |
| J-Find | 指定毕业院校、毕业时间、学历、资金与活动条件 |
| 留学 | 学校与课程入学条件、资金、在留活动；不能把语校材料要求套到全部学位项目 |
| 经营・管理 | 当前生效标准及过渡规则、实际经营与人员／办公要求 |

入口：[在留资格一览](https://www.moj.go.jp/isa/applications/status/index.html)、[J-Find外务省说明](https://www.mofa.go.jp/ca/fna/page22e_001037.html)。

## 高度人才积分：用官方表逐项举证

[高度人才官方Q&A](https://www.moj.go.jp/isa/applications/resources/newimmiact_3_qa.html)与[官方积分表](https://www.moj.go.jp/isa/content/930001657.pdf)是核对入口。必须选择对应活动类别，检查年龄、收入、学历、经验及加分项注释。

重点避免以下误算：

- 学历与同类资格不是任意累加；多个学位的条件按官方表判断。
- 日本学历与N2等奖励存在不可重复计算的情形；不能把所有语言、留学加分无条件相加。
- 中国软考与日本考试互认，不等于每个证书都能按“一个10分、两个15分”计入HSP。本次删除该简化规则与依赖它的85分示例，具体证书和对应条款需另行核验。
- 院校、雇主、研究实绩加分需要对应官方名单和证明；论文数、专利或学校品牌本身不保证加分。
- 申请时与历史时点的积分要分别证明，不能只用今天的积分回推过去。

## 永住：先区分申请年限与审理结果

官方制度对符合条件的高度人才提供70分／3年、80分／1年的在留年限特例。是否满足历史时点、持续在留、当前在留期间及其他条件，要按对应申请类别判断；不能理解为落地一年自动获批，也不一定需要先换成HSP才可使用相关特例。

核对：[高度人才优遇措施](https://www.moj.go.jp/isa/applications/resources/newimmiact_3_preferential_index.html)、[永住指南](https://www.moj.go.jp/isa/10_00279.html)、[永住申请入口](https://www.moj.go.jp/isa/applications/guide/eizyuu.html)。

税款、年金、医保及申报义务应按时履行，并保存缴费证据。迟缴可能影响审查；本项目不再使用“晚一天必拒、全部重算”的统一断言。请按对应类别的官方材料清单检查需要覆盖的期间，例如[高度人才申请资料](https://www.moj.go.jp/isa/applications/procedures/nyuukokukanri07_00130.html)。

## 求职与材料准备

可在[TokyoDev](https://www.tokyodev.com/)和[Japan Dev](https://japan-dev.com/)等站点寻找岗位，再逐个确认工作地点、语言、经验与是否接收海外申请者。岗位是否存在与签证资格分别判断。

准备学历、合同、职责、收入、税务及社保证据，确保真实一致。预算分开列考试、翻译、签证、搬迁和租房费用；不使用“零成本”“固定年薪”“包永住”的承诺。
