# 🇭🇰 中国香港：高才通、优才、IANG与续签资料目录

修订日期：2026-10-25。首次获批、延期逗留与永久居民资格是独立判断，不提供“秒批”“包续签”承诺。

## 1. 选择路径

| 计划 | 主要核对入口 |
| :--- | :--- |
| 高才通（TTPS） | A／B／C类别各自的收入、学位、工作经验与当期名单条件 |
| 优才（QMAS） | 基本资格、适用评核制度、证明材料与遴选安排 |
| IANG | 课程与毕业资格、应届／非应届类别及申请时点 |
| 输入内地人才计划（ASMTP） | 雇主、岗位、申请人能力、薪酬和雇佣证明 |

官方：[TTPS](https://www.immd.gov.hk/hks/services/visas/TTPS.html)、[QMAS](https://www.immd.gov.hk/hks/services/visas/quality_migrant_admission_scheme.html)、[IANG](https://www.immd.gov.hk/eng/services/visas/IANG.html)、[ASMTP](https://www.immd.gov.hk/hks/services/visas/ASMTP.html)。

高才通B／C的学位层次和大学综合名单应逐项核对，不以“读过全球百强硕士”直接认定符合。优才也不能仅凭学校、公司名称或六级成绩口头凑项。本次移除了未经逐项核验的12项简化表与“秒过组合”。

## 2. IANG并非毕业自动获批

应届与非应届毕业生条件不同，是否需要先有工作取决于类别及申请时点。合资格申请人获批后通常有24个月首次逗留期限；仍需提交申请并满足正常入境要求。查看[官方FAQ](https://www.immd.gov.hk/eng/faq/non-local-graduates-return-employment-arrangement.html)。

学校录取、学生签证、毕业和IANG是不同步骤。课程是不是一年制，不足以单独判断能否适用。

## 3. 续签与通常居住分别整理

按自己的计划核对延期逗留要求，保存实际工作的职责、合同、薪酬和适用税务资料，或真实经营的业务、客户及财务资料。跨境办公、自雇、佣金收入等情况应按实际事实说明，不能承诺“挂一家香港公司即可续签”。

永久居民资格涉及适用的通常居住规则；不是累计持签七年就自动取得，也不能简化成“读一年＋工作六年必然够”。请从入境处[永久性居民资格核实入口](https://www.immd.gov.hk/hks/services/roa/eligible.html)核对对应类别。

香港居民身份证、永久居民身份、国籍、特区护照、税务和子女升学资格，分别适用各自规则；本页不再把其中一项获批宣传成其他权益一并保证。

## 4. 费用：把官费与其他开支分开

指定计划的现行收费结构（官方页面核对日期：2026-10-25）：

| 项目 | 港币 | 说明 |
| :--- | ---: | :--- |
| 申请费 | 600／每名申请人每次申请 | 主申请人及受养人分别计；不论结果均不退还 |
| 签发费：相关期间超过180日 | 1,300 | 期间按官方定义计算 |
| 签发费：相关期间不超过180日 | 600 | 期间按官方定义计算 |

来源：[入境处指定计划收费说明](https://www.immd.gov.hk/eng/specifiedschemes.html)。例如适用600申请费和1,300签发费时，合计是**1,900港币官费**；不能把它直接等同于某个固定人民币“全部成本”。延期亦可能产生新费用。

翻译认证、通行证及签注、交通、住所和生活费单独预算。

## 5. 材料自查

- 用官方清单确认学历认证、收入期间、工作经验和家属证明。
- 逐项对应证据；材料缺口不通过虚构雇佣或经营补足。
- 记录批出条件、逗留期限与延期窗口；本次未对所有计划续签年期和特殊安排逐条验证，申请前查对应页面。
- 不公开护照、身份证号码、税单或完整申请档案。
