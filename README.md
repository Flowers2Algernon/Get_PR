# 🌍 Get_PR：工作签证、人才计划与永久居留 DIY 手册

**澳大利亚 · 日本 · 美国 · 中国香港 · 欧洲**

从官方资料开始，梳理申请资格、材料准备、工作居留与后续永久居留的不同阶段。适合希望自行研究海外工作与身份路径的读者。

> **使用前请读**：这是社区维护的信息目录，不是官方申请系统或个案法律意见。获邀、申请受理、签证获批与永久居留是不同阶段；本项目不预测获批概率。审查记录见 [2026-10-25 内容审查](./docs/review-2026-10-25.md)。

## 从这里开始

1. 确定目标：找工作、留学、临时工作居留，还是永久居留。
2. 阅读对应章节，逐项核对官方资格与材料。
3. 用 [通用材料清单](./templates/diy-checklist-and-sop.md) 整理已有证据；不要提前购买全部公证或认证。
4. 分别预算官费、翻译认证、考试、生活、家属和可选专业服务。金额使用当地货币并注明日期。

### 澳洲 EOI 估算工具

[打开 EOI 积分估算器](https://htmlpreview.github.io/?https://github.com/Flowers2Algernon/Get_PR/blob/main/docs/01-australia/eoi-calculator.html)

手动选择可举证的积分条件。190的5分和491的15分展示为**取得相应提名／担保后的假设情景**。工具不自动认定工作年限，不比较未经逐轮核实的职业邀请分数，也不判断是否会获邀。

## 资料状态与维护方式

- 修订日期：**2026-10-25**。该日期表示本次内容审查，不表示所有政策已全面验证。
- 各章节列出官方核对入口；无法确认的金额、等待年数、资格细节与预测不作为定论。
- 官方页面读取受限、政策未完成逐条核对的地方，在审查记录中列为待核验。
- 费用、薪资线、大学名单、考试标准和邀请轮次会变化；实际申请时重新核查。
