## 💡 项目背景与核心原则 (Why This Repository?)

在研究海外职业发展与全球身份规划时，申请人往往面临两大痛点：一是互联网上的零散经验贴严重滞后于各国频繁变动的移民法案；二是传统咨询机构存在高昂的信息差溢价，且往往重“首次获批”而轻“后续续签与永居合规”。

本开源手册坚持三个核心原则：
1. **官方信源驱动（Source of Truth）**：所有打分表、薪资基准线、职业评估规则及政府规费均直接对齐各国移民局与劳工部最新官方条款。
2. **全链路合规视角（Entry to PR）**：不仅拆解如何获取首张签证，更重点剖析**职业评估年限折算、续签实质审查、税务社保合规**等决定最终能否顺利拿到永居（PR）的关键节点。
3. **倡导独立 DIY（100% DIY-Friendly）**：绝大多数技术移民、人才计划与工作签证均拥有极其透明的官方审理标准，具备基本检索与文档整理能力的专业人士完全可以独立完成申请。
