# 🇪🇺 欧洲：德国、荷兰与南欧工作居留资料目录

修订日期：2026-10-25。欧洲各国签证、长期居留和入籍规则分别适用；某国居留不等于在其他申根国家自由就业。

## 1. 德国：蓝卡与机会卡分开看

| 类别 | 用途 | 核对重点 |
| :--- | :--- | :--- |
| 欧盟蓝卡 | 在德国从事合格工作 | 资格、岗位匹配、工作期限、薪资及适用批准 |
| 机会卡 | 赴德寻找工作 | 德国认可资格路径或积分路径、生活保障与许可活动 |

### 欧盟蓝卡

2026年一般税前年薪门槛为**50,700欧元**。符合紧缺职业或近三年毕业的青年专业人士等条件，可适用**45,934.20欧元**的较低门槛，并涉及联邦就业局批准；具体类别分别核对。

须有至少六个月的合适工作。IT无学位例外有明确的经验层次与期间要求，不能概括为“任意三年IT经验”。

蓝卡相关永居路径通常涉及合格就业、养老保险、语言及其他条件：27个月／A1，满足B1可缩短至21个月。这是满足条件后申请的路径，不能从开始留学计时或保证到期批准。

来源：[德国政府蓝卡说明](https://www.make-it-in-germany.com/en/visa-recognition/visa-types/eu-blue-card)、[柏林政府永居清单](https://service.berlin.de/dienstleistung/326556/en/)。

### 机会卡

- **德国认可资格路径**：符合该路径可不经积分制，官方说明该路径不要求另行提供语言证明；仍需生活保障等条件。
- **积分路径**：符合资格基础、德语A1或英语B2等要求，并达到至少6分。
- 2026年政府页面列出的冻结账户生活保障参考为**每月1,091欧元**，亦列有担保声明等证明方式；不是所有申请人都只能使用同一家冻结账户服务商。
- 学校的Anabin H+状态不等于你的具体学位一定已完成等效认定；学校与资格证明分别核对。

来源：[机会卡官方条件](https://www.make-it-in-germany.com/en/visa-recognition/opportunity-card/job-search)、[Anabin](https://anabin.kmk.org/)。

## 2. 荷兰：HSM与Orientation Year

[IND 2026薪资标准](https://ind.nl/en/news/fees-and-required-amounts-for-2026-known)列明，不含假期津贴的月薪门槛：

| HSM类别 | 2026年欧元／月 |
| :--- | ---: |
| 30岁及以上 | 5,942 |
| 30岁以下 | 4,357 |
| 符合较低薪资标准的申请人 | 3,122 |

这些是2026年度金额，不是永久不变的门槛。较低标准的首次适用、续签、换雇主等条件应查[IND当前金额与适用条件](https://ind.nl/en/required-amounts-income-requirements)，不宣传为“先办求职年即可终身锁定3,122欧元”。

### 海外学历求职年

海外学历路径与荷兰本地毕业／研究路径不同。对海外指定院校学历，需要核对近三年内符合条件的课程、毕业时点至少两个指定排名出版机构的前200要求、学科榜与所学领域关系、语言／豁免及学历评估。不是“任一榜前200即可”，也不是仅有海外本科学位即可。

申请方式取决于所在地及身份，不能把国外申请统一写成直接在线完成。

来源：[IND求职年要求与流程](https://ind.nl/en/residence-permits/work/residence-permit-for-orientation-year)。

## 3. 西班牙与葡萄牙：远程工作居留待专项核验

本次移除了将旧年度最低工资写成2026标准的固定收入表，以及把两国居留、永居、入籍和语言条件合并的结论。具体金额与当前法律尚待专项核验，不作为已确认申请指南。

研究时分别核对：

1. 雇员远程工作与自雇／自由职业条件。
2. 申请地点、合法停留、许可期限及实际可从事活动。
3. 主申请人与家属收入计算、社保、保险及税务。
4. 永居与入籍各自的居住、离境、语言及其他条件。

合同应与真实工作关系一致；不为规避要求而将实际雇佣包装成B2B。本次不推荐固定合同模式或“旅游入境即可批三年”的统一方案。

## 4. 申请前整理

确定岗位／收入来源 → 核对学历与专业资格 → 核对申请类别和所在地程序 → 按当地货币做预算 → 逐项准备材料 → 记录续签与长期居留条件。

生活成本、租房、税负与工作语言因城市和岗位而异，不以“欧洲都不加班”“只用英语”“存够固定金额即可”的口号替代调查。入籍规则也不能从永居条件推导。
