# 📋 DIY基础档案与材料核对清单

修订日期：2026-10-25。**这是整理档案的可选清单，不是所有国家的统一必交材料。** 以目标机关的现行清单为准，确认后再支付公证、认证、翻译和评估费用。

## 1. 先建立申请记录

- [ ] 目的地、签证类别、申请所在地、主申请人及家属类别。
- [ ] 官方材料清单链接、访问日期、表格版本与截止日期。
- [ ] 每项证据状态：已有／缺失／需更新／不适用。
- [ ] 是否需要原件、扫描件、认证副本、直接寄送或指定格式。

## 2. 身份与家庭资料

- [ ] 护照及所需页面；有效期与扫描范围按具体清单。
- [ ] 身份、出生、婚姻或伴侣关系证明，仅在要求时提供。
- [ ] 无犯罪证明：查需覆盖哪些居住地、何时开具、有效期、翻译及提交方式。不要统一假定3–6个月或所有地方均能全程网上办理。
- [ ] 家属资料与申请条件单独核对。

## 3. 学历与语言资料

- [ ] 学位、毕业证明、成绩单、课程说明（需要时）。
- [ ] 核对是否要求CHSI、留服、ZAB、Nuffic或其他评估；这些报告不能互相替代，也不是人人必交。
- [ ] 指定发送渠道、机构资质与报告期限。
- [ ] 语言考试版本、考试日期、各项分数、有效性、允许的证明或豁免。CET-6等证明仅在对应制度明确接受时使用。

## 4. 工作与财务资料

可先整理雇主证明、合同、工资、银行流水、税务或社保资料，再按正式清单选择提交。不存在跨所有国家统一强制的“五证合一”。

- [ ] 工作职责如实反映实际工作，不照抄职业定义或虚构项目。
- [ ] 任职日期、工时、报酬、公司主体和签署人信息可核对。
- [ ] 按要求准备工资、税务或其他独立佐证。
- [ ] 兼职、自雇、派遣、无薪阶段、税期差异与合理时间差清楚说明。
- [ ] 雇主解散或无法取得证明时，查是否有认可的替代证据。
- [ ] 对外披露雇主或客户材料前，检查授权及保密要求。

## 5. 翻译、公证与Apostille

分别回答四个问题：**要哪份原始文件？要什么译文？要公证或认证副本吗？要Apostille／领事认证吗？**

不能按“整个欧洲必须海牙认证”“澳洲一概不需要”“香港永远无需翻译”等地域口号判断。Apostille、公证、翻译和学历等效评估作用不同；是否需要及适用方式由文件性质、出具地、接收机关和条约适用关系决定。

官方核对入口：

- [HCCH Apostille公约专题](https://www.hcch.net/en/instruments/conventions/specialised-sections/apostille)：成员、适用关系和主管机关。
- [荷兰IND求职年材料与翻译说明](https://ind.nl/en/residence-permits/work/residence-permit-for-orientation-year)。
- [USCIS I-140表格与说明](https://www.uscis.gov/i-140)。
- [香港高才通申请说明](https://www.immd.gov.hk/hks/services/visas/TTPS.html)。

## 6. 文件与隐私

建议本地文件夹：01-identity、02-education、03-work、04-finance、05-translations、06-submitted。保留原始文件、译文、版本和提交回执。

- [ ] 文件名注明日期与用途，不修改原始内容。
- [ ] 公开讨论仅用脱敏样例；护照、完整税单、银行资料及密码不上传公开GitHub。
- [ ] 保存备份；提交前复核个人信息、签字、日期、费用、版本及上传清单。
