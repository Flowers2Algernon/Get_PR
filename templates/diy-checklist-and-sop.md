# 📋 全球签证与技术移民 DIY 通用材料总表 (Master Checklist & SOP)

> **核心原则**：无论你申请 **澳大利亚 (189/190)、日本 (高度人才)、美国 (NIW/EB-1A)、香港 (高才/优才) 还是欧洲 (德国蓝卡/机会卡/数字游民)**，各国移民官审核你底层材料的逻辑都是高度相通的——**“身份真实、学历合规、工作履历闭环（职权+资金流+税单对得上）、无安全隐患”**。  
> 提前按本表把你的个人基础档案数字化归档，能帮你省下 90% 的重复跑腿时间与数万元中介文案费。

## 一、 四大底层材料模块清单 (Digital Archive Checklist)

### 模块 1：身份与家庭关系类（全员必备）
- [ ] **护照扫描件**：有效期至少在 18 个月以上，彩色高清扫描整本（含所有资料页、签字页及过往签证出入境章页）。
- [ ] **身份证与户口本**：正反面彩色扫描件。
- [ ] **出生公证书 / 出生医学证明公证**：澳洲 PR、美国绿卡（I-485/CP阶段）、欧洲家庭团聚必用（中英双语公证，涉欧需加办**海牙认证 Apostille**）。
- [ ] **结婚证公证**（如已婚携签）：中英双语公证（涉欧加海牙认证）。
- [ ] **无犯罪记录证明及公证**：
  * **注意时效性**：各国通常要求无犯罪证明在递交前 **3~6 个月内**开具（切勿提前一年开，过期作废！）。
  * **开具技巧**：现在全国绝大部分省市均可通过微信/支付宝政务小程序（如“随申办”、“粤省事”、“浙里办”、“北京警务”）在线开具带电子印章的《无犯罪记录证明》PDF，直接发给公证处线上申办涉外公证 + 海牙认证，全程无需跑派出所！

---

### 模块 2：学历与语言证明类（评估与算分核心）
- [ ] **毕业证书 + 学位证书**（本、硕、博全套原件高清彩色扫描）。
- [ ] **大学正式成绩单 (Official Transcripts)**：需盖教务处或档案馆红章（最好直接由学校开具中英文对照版）。
- [ ] **中国教育部学信网 (CHSI) 认证三件套**：
  1. 《教育部学历证书电子注册备案表》（中文/英文翻译件）
  2. 《中国高等教育学位在线验证报告》（中文/英文翻译件）
  3. 《中国高等教育成绩验证报告》（香港高才/优才、澳洲 VETASSESS、德国 ZAB、美国 WES 认证常备）
- [ ] **海外学历认证**（如有海归背景）：教育部留学服务中心《国外学历学位认证书》，以及毕业院校官方 Electronic Transcript。
- [ ] **语言考试成绩单**：雅思 (IELTS) / PTE Academic / 托福 (TOEFL) / 日语 JLPT N1/N2 / 英语六级 CET-6 成绩单。

---

### 模块 3：工作经验与财税铁证闭环（90% DIY 拒签/补件的重灾区！）
各国移民局（尤其是澳洲 ACS/VETASSESS、香港优才/高才、日本入管局、美国 USCIS）核查工作经验时，绝不再只看一纸盖章证明，而是要求 **“五证合一”**：

- [ ] **1. 雇主推荐信 / 工作证明信 (Reference Letter)**：
  * **标准格式要素**：必须使用公司官方抬头纸（Letterhead，含公司 Logo、地址、电话、官网） -> 注明你的准确入离职日期（精确到日）、全职（Full-time）周工时（如 40 hours/week）、职位名称、年薪总额 -> **核心灵魂：列出 5~8 条极其详尽的日常岗位职责与核心项目产出**（切忌一句话带过，必须贴合目标国职业评估代码如澳洲 ANZSCO 的官方职责定义！） -> 直属主管或 HR 签字、职务、联系方式及公司公章。
- [ ] **2. 劳动合同 (Employment Contracts)** + 离职证明 (Release Letter)。
- [ ] **3. 个人所得税 App 官方证明（铁证之王）**：
  * 登录“个人所得税”App -> 开具带税务局电子红章的 **《纳税记录》** + 导出 **《收入纳税明细》** 截图（清晰显示扣缴义务人公司全称与每月申报工资额）。
- [ ] **4. 社保证明 (Social Insurance Record)**：各地人社局小程序下载带电子章的《城镇职工基本养老保险参保缴费证明》（证明确实由该公司为你缴纳社保）。
- [ ] **5. 银行工资流水 (Bank Statements)**：标出每月“工资/代发薪酬”字样的条目。

> 🛠️ **雇主推荐信防拒签铁律**：  
> 切勿自己瞎编中式英语流水账！撰写英文/日文推荐信时，务必严格对齐目标国官方职业标准（如澳洲 ANZSCO/OSCA、加拿大 NOC 或美国 SOC 代码的官方职责描述），并确保你上传的个税单、社保证明与推荐信上的入离职时间线不存在任何断档冲突。

## 二、 常见跨国认证防坑快查表

| 目的国/地区 | 学历需要什么认证？ | 公证书需要海牙认证 (Apostille) 吗？ | 官方材料语言要求 |
| :--- | :--- | :--- | :--- |
| **🇦🇺 澳大利亚** | 学信网全套报告（部分职评机构要求从学信网直发或公证） | ❌ 不需要海牙，国内涉外中英公证书即可 | 英文（非英文材料需 NAATI 认证翻译或国内涉外公证） |
| **🇯🇵 日本** | 学信网电子注册备案表 + 学位验证报告 | ❌ 不需要海牙 | 日文或英文（入管局接受附上日文翻译件并由翻译者署名） |
| **🇺🇸 美国** | 非美学位申 NIW/EB-1A 需做 **NACES 会员机构等效认证**（如 WES / ECE / Morningside，证明等同于美国 Master/Bachelor） | ❌ 不需要海牙（广领馆面签阶段带国内中英公证书原件即可） | 英文（所有中文证据需附完整英文翻译 + 译者声明 Certificate of Translation） |
| **🇭🇰 中国香港** | 学信网《学位在线验证报告》+《学历备案表》（海归需留服认证） | ❌ 不需要公证或海牙（在线直接上传原件扫描件即可！） | 中文（简/繁皆可！）或英文 —— **全球唯一可直接交简体中文材料的地区** |
| **🇪🇺 德国 / 荷兰 / 西班牙** | 德国查 **Anabin (H+)** 或做 **ZAB 认证**；西班牙需学信网及学位公证 | ✅ **必须办海牙认证 (Apostille)！**（公证处出公证书后，送省/市外事办贴海牙附加证明书） | 德/英（德国）、英/荷（荷兰）、西班牙官方宣誓翻译西语（西班牙） |
