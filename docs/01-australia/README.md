# 🇦🇺 澳大利亚：技术移民与工作签证 DIY 入门

修订日期：2026-10-25。下列为研究框架，资格、考试与费用以申请时官方规定为准；不提供职业获邀预测。

## 1. 分清申请阶段

职业与签证类别核对 → 职业评估和英语证明 → 积分及州／领地条件核对 → EOI／适用的州申请 → 获邀 → 正式签证申请 → 审理决定。

**EOI不等于签证申请，获邀不等于PR。** 189／190在签证获批后取得永久居留；491是临时签证，后续191需要另行满足适用条件。

| 路径 | 需要核对的事项 |
| :--- | :--- |
| 189 打分制 | 合格职业、评估、英语、获邀时年龄与积分、健康及品格等 |
| 190 | 联邦条件加州／领地提名条件；满足最低要求不保证提名 |
| 491 | 州／领地提名或合资格亲属担保；核对地区与签证条件 |
| 482（SID）／186 | 分别核对雇主、岗位、经验、英语、薪资、提名及年龄／豁免；工作满两年不代表自动获批186 |

来源：[189](https://immi.homeaffairs.gov.au/visas/getting-a-visa/visa-listing/skilled-independent-189/points-tested)、[190](https://immi.homeaffairs.gov.au/visas/getting-a-visa/visa-listing/skilled-nominated-190)、[491](https://immi.homeaffairs.gov.au/visas/getting-a-visa/visa-listing/skilled-work-regional-provisional-491)、[482](https://immi.homeaffairs.gov.au/visas/getting-a-visa/visa-listing/skills-in-demand-visa-subclass-482)、[186](https://immi.homeaffairs.gov.au/visas/getting-a-visa/visa-listing/employer-nomination-scheme-186)。

## 2. EOI积分估算

[积分估算器](https://htmlpreview.github.io/?https://github.com/Flowers2Algernon/Get_PR/blob/main/docs/01-australia/eoi-calculator.html)仅汇总你选择的条件，不审核证明材料。先算已经满足的积分，再单独列出未来计划。

| 项目 | 分值概览 | 注意事项 |
| :--- | :--- | :--- |
| 年龄 | 18–24：25；25–32：30；33–39：25；40–44：15 | 以获邀时年龄及适用规则核对 |
| 英语 | Competent：0；Proficient：10；Superior：20 | 0分仍需满足Competent；未满足者不能仅靠其他积分补足 |
| 过去10年海外合格工作 | 不足3年：0；3–4年：5；5–7年：10；8年及以上：15 | 仅计算满足规则且可举证的相关工作 |
| 过去10年澳洲合格工作 | 不足1年：0；1–2年：5；3–4年：10；5–7年：15；8年及以上：20 | 境内外工作合计最高20分；不能重复计算同一期间 |
| 学历 | 博士20；合格学士／硕士15；符合规定的其他资格10 | 资格认可与具体条件须核对 |
| 配偶／伴侣 | 符合规则的10分、5分或0分 | 不仅看婚姻登记；需核对事实伴侣、共同申请与职业等条件 |
| 其他 | 澳洲学习5、偏远学习5、专业研究资格10、社区语言5、职业年5 | 每项有独立条件、有效期或课程要求 |
| 提名／担保 | 190：5；491：15 | 仅在取得相应提名／合资格担保时适用；不能同时叠加 |

官方依据：[189积分表](https://immi.homeaffairs.gov.au/visas/getting-a-visa/visa-listing/skilled-independent-189/points-table)、[EOI说明](https://immi.homeaffairs.gov.au/visas/working-in-australia/skillselect/expression-of-interest)。65分是最低积分门槛，**不保证获邀**。

### 英语核对入口

[Competent](https://immi.homeaffairs.gov.au/help-support/meeting-our-requirements/english-language/competent-english)、[Proficient](https://immi.homeaffairs.gov.au/help-support/meeting-our-requirements/english-language/proficient-english)、[Superior](https://immi.homeaffairs.gov.au/help-support/meeting-our-requirements/english-language/superior-english)。

考试种类、考试日期、各单项分数和成绩有效性均须核对。移民局英语要求与学校、职业注册、职业评估的英语要求不同；不能相互替代。本次移除了未按考试日期区分的托福表，不在工具中自动判定考试成绩。

## 3. 职业评估与工作年限

先查目标职业对应的机构与申请路径，再阅读该机构材料要求：

- [Engineers Australia](https://www.engineersaustralia.org.au/)：认证课程、毕业年份、认可层次及CDR路径分别判断。学校名称不能代替具体课程认证。
- [ACS](https://www.acs.org.au/)：按申请路径、学历和工作证据判断，不用“所有IT申请固定扣两年”替代结果。
- [VETASSESS](https://www.vetassess.com.au/)：按职业、学历相关性及适用经验规则核对。
- 护理、教师、社工等，须另查目标职业当时指定的评估／注册机构，避免把所有教育职业统一归于同一机构。

**工具不自动扣年限。** 评估信、相关工作、可主张积分的期间与签证规则要一起核对。缺少材料、兼职、自雇或重叠工作需分别处理，不预设一定可算或一定不可算。

## 4. 邀请和州政策

查阅[官方邀请轮次](https://immi.homeaffairs.gov.au/visas/working-in-australia/skillselect/invitation-rounds)，记录**轮次日期、签证类别、具体职业代码、最低分及适用说明**。某轮最低分不等于下一轮保证线，也不能用189的分数判断190。

各州当期规则、职业列表、地区定义及申请窗口需查州政府官网。本文已移除缺少逐轮来源的职业分数表、职业“稳拿PR”评级和各州“潜规则”。

## 5. 时间与预算

分别预算评估、考试、签证、家属、翻译、体检、无犯罪证明、搬迁及生活费。官费使用[移民局费用页面](https://immi.homeaffairs.gov.au/visas/visa-pricing-estimator)，评估费查对应机构；本页不把人民币换算或个人生活预算写成统一官方费用。

留学前还需单独核对课程认证、实习注册与[485适用条件](https://immi.homeaffairs.gov.au/visas/getting-a-visa/visa-listing/temporary-graduate-485)，包含年龄及例外。毕业、职评和工作机会均不构成永居保证。
