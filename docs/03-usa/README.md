# 🇺🇸 美国：职业移民请愿与工作签证 DIY 研究框架

修订日期：2026-10-25。以下提供官方资料索引与证据整理方法，不预测排期、成功率或个案法律结果。

## 1. 先分清四件事

1. **I-140移民请愿**：判断是否符合职业移民分类。
2. **签证名额与优先日**：由类别、出生地对应的配额规则及每月排期等决定。
3. **移民签证／I-485身份调整**：另有资格、程序、材料及费用。
4. **现有合法身份与工作许可**：不能用I-140收据或批准替代。

获批NIW、EB-1A或持有优先日，不等于已经取得绿卡、入境资格或工作授权；也不自动满足O-1条件。

| 路径 | 谁提出申请／请愿 | 要点 |
| :--- | :--- | :--- |
| EB-2 NIW | 可自行请愿 | 先符合EB-2，再证明NIW三要素 |
| EB-1A | 可自行请愿 | 证据门槛与整体实质审查均要满足 |
| EB-1C | 合资格美国雇主 | 跨国企业关系、管理／高管职责与任职期间等分别判断 |
| O-1 | 合资格美国雇主或代理等 | 工作签证类别，不能把NIW获批视为O-1自动获批 |
| L-1 | 合资格企业 | 企业关系、海外任职与赴美职责等须核对；不直接给绿卡 |
| 常规EB-2／EB-3 | 通常由雇主主导 | 劳工证及适用例外、岗位与申请条件另查 |

## 2. NIW：分类资格与国家利益豁免分开证明

先看高等学位专业人士或特殊能力的基础资格，再论证拟从事事业的价值与国家重要性、本人推进事业的有利条件，以及综合而言豁免工作邀请和劳工证要求对美国是否有利。

硕士学历、论文、引用、开源Star或高薪，都不能单独保证NIW。不要用“若干论文／几十引用稳过”代替证据分析，也不要把某行业很重要直接当成你的具体事业具有国家重要性。

官方：[EB-2概览](https://www.uscis.gov/working-in-the-united-states/permanent-workers/employment-based-immigration-second-preference-eb-2)、[Policy Manual 6-F-5](https://www.uscis.gov/policy-manual/volume-6-part-f-chapter-5)。

## 3. EB-1A：满足若干证据类别不等于获批

除适用的重大单项成就路径外，通常需满足法规规定的至少三项证据类别；USCIS还会综合全部证据进行final merits审查。不能写成“十选三就是快速绿卡”。

证据应展示实际影响、本人角色、独立评价及来源，而不是仅堆数量。推荐信与项目数据应真实、可核对，注意获得材料披露授权。

官方：[Policy Manual 6-F-2](https://www.uscis.gov/policy-manual/volume-6-part-f-chapter-2)。

## 4. 实用证据目录

| 文件夹 | 可整理的资料 | 核对问题 |
| :--- | :--- | :--- |
| 01-qualification | 学历、成绩、学历等效评估及经验 | 是否满足所选分类，而非只满足某个模板 |
| 02-endeavor | 拟开展工作的具体说明与独立背景证据 | 目标、范围与本人计划是否清楚 |
| 03-track-record | 项目、成果、采用情况与客观数据 | 贡献是否能归属于本人、数据能否验证 |
| 04-external-evidence | 独立专家评价、客户／采用方证明 | 评价是否具体且有依据 |
| 05-forms-index | 现行表格、译文、索引与提交记录 | 版本、签名、费用及地址是否匹配 |

并非每一类资料都是所有申请必需；学历评估机构与材料格式按实际分类和官方要求判断，不将NACES会员资格写成所有案件统一强制条件。

## 5. 排期、费用与后续安排

- 每月核对[国务院Visa Bulletin](https://travel.state.gov/content/travel/en/legal/visa-law0/visa-bulletin.html)，区分Final Action Dates与Dates for Filing；在美身份调整还要核对USCIS当月指定用表。
- 某月截止日与今天的日期差，不能直接换算为新申请人的固定等待年数。优先日保留亦有适用条件及例外，不能承诺终身绝对有效。
- 使用[I-140页面](https://www.uscis.gov/i-140)核对现行版本、提交方式及地址；费用查[G-1055](https://www.uscis.gov/g-1055)。请愿、可选加急、后续移民程序、家属、体检与翻译分别预算。
- 加急服务承诺的是规定时限内采取审理行动，可能是补件等，不是保证批准或缩短签证排期。

**核验范围**：本次通过USCIS官方检索结果核对核心审查框架，部分完整正文直接访问受限。具体费用、加急时限、跨国企业个案条件及身份衔接仍应查现行原文或取得适当专业意见。
